🚀 Como colocar em produção no GitHub Pages:

  1. Acesse o Google Cloud Console e crie um projeto de teste.
  2. Em Credenciais, crie um ID do cliente OAuth (Web Application).
  3. Em Origens JavaScript Autorizadas, adicione o endereço do seu site: https://webappssvp.github.io.
  4. Substitua o data-client_id na tag #g_id_onload deste arquivo pelo seu ID real gerado.
  5. Faça o commit e push deste arquivo para o GitHub para testar em tempo real no ar!
